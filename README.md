# Dart Tracker

Mała, wieloplatformowa aplikacja Flutter dla darcistów - do notowania wyników, treningu i podstawowych statystyk z gry w darta. Repozytorium: `Owczany/dart-tracker`.

## Funkcje
> **Uwaga:** wczesna wersja/MVP — lista funkcji może się zmieniać.
- Szybkie liczenie punktów w różnych trybach
- Historia gier i prosty podgląd statystyk (średnia na rzut/leg, % checkoutów).
- Wieloosobowe rozgrywki (lokalnie).
- Tryb web/desktop/mobile (Flutter).
